# Agent logos

Each file here is a colour or mono SVG from `@lobehub/icons-static-svg` 1.95.1
(https://github.com/lobehub/lobe-icons), MIT licensed, copied as a plain `.svg`:

- `claude.svg` is `claude-color.svg`, Claude's mark in its own orange. Claude Code and Claude
  Desktop both draw it.
- `codex.svg` is `codex-color.svg`, the Codex app mark.
- `grok.svg` is `grok.svg`, Grok's mark, which the brand draws in one colour.
- `hermes.svg` is `hermesagent.svg`, the Nous Research mark the package titles Hermes Agent.

Each file's `viewBox` is widened from `0 0 24 24` to `-4 -4 32 32`, because these marks fill their
whole box and a coin logo sits in the middle three quarters of its own: the same widening puts
every agent mark at the size a coin's mark is drawn. Nothing else in the files is changed.

The marks are trademarks of their owners (Anthropic, OpenAI, xAI, Nous Research) and are used
here only to name the agent a row is about. "Another agent" is any MCP client at all, so it
draws the app's own link icon (ui/design/icons.js), not anybody's mark.
